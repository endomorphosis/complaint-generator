Operational administration

Account changes use ordinary HTTP requests. WebSocket and server-sent events are not used. This screen lists least-privilege account fields only. It does not decrypt or enumerate case narratives, messages, evidence, keys, or summaries. Audit history is a separate right from account administration. Operations inspection shows case counts, assignment status, and storage or worker states without opening owner envelopes. Incident handling does not impersonate a case owner and does not grant case content. Signing in again is required after a reload because the CSRF token is kept in memory only.
